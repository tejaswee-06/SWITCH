switch_villa.glb — the runtime 3D model loaded by the app (local file, no external viewer).

It is generated by blender/build_villa.py (Blender 5.2.2 via the bpy module) together with
blender/out/switch_villa.blend. It is an original procedural reconstruction; no third-party
(Sketchfab / Fab) geometry is included.

Interactive objects carry glTF extras (device_id, kind, room, level) and each room has an authored
CAM_<ROOM> camera. After regenerating, run `npm run test:geometry` to re-validate rooms, devices,
camera presets and walk collision.
